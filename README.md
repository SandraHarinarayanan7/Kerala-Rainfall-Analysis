# Kerala Rainfall Analysis – Power BI

## Project Overview

This project focuses on analyzing rainfall patterns across Kerala using Power BI. The dashboard transforms rainfall and weather data into meaningful visual insights, helping to understand variations in rainfall across districts, months, and seasons.

The project involved data cleaning and preparation, followed by interactive data visualization and analysis in Power BI. The final dashboard provides a clear overview of rainfall trends, district-wise distribution, seasonal patterns, rainy days, rainfall categories, and temperature variations across Kerala.

## Objectives

- Analyze rainfall patterns across different districts of Kerala
  
- Identify monthly and seasonal variations in rainfall
  
- Compare rainfall levels across districts
  
- Analyze rainfall categories and rainy-day patterns
  
- Examine temperature variations across different months
  
- Present key findings through an interactive Power BI dashboard

## Data Preparation

The raw dataset was cleaned and prepared before developing the dashboard. The data preparation process included reviewing the dataset, handling inconsistencies, checking data quality, and transforming the data into a suitable format for analysis and visualization.

## Dashboard Highlights

The Power BI dashboard provides insights into:

- Total, average, and maximum rainfall
  
- Total rainy days
  
- Monthly rainfall trends
  
- District-wise rainfall distribution
  
- Seasonal rainfall comparison
  
- Rainfall category distribution
  
- Top districts by rainfall
  
- Average temperature by month
  
- Interactive filtering by district, season, and month

## Tools & Technologies

- Power BI
  
- Microsoft Excel
  
- Power Query
  
- DAX
  
- Data Cleaning & Transformation
  
- Data Visualization

## Key Insights

The dashboard helps identify differences in rainfall patterns across Kerala and highlights variations between districts, months, and seasons. It also provides an overview of rainfall intensity and temperature patterns, making the data easier to interpret through interactive visualizations.

## Conclusion

This project demonstrates the use of data cleaning, analysis, and visualization techniques to transform raw rainfall data into an interactive Power BI dashboard. It showcases how data can be presented through meaningful KPIs and visualizations to identify patterns and generate useful insights.
